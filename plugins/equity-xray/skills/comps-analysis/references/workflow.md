# 两种同行工作流

## A 经营模式与竞争比较
使用核心peer-comparison.md确定产品、模式、收入、客户、定位和规模可比性；用户指定两家就比较这两家并揭示不可比部分，不强凑3–5家。
将收入来源、价值链位置、资本密集度、渠道、客户集中、研发/销售投入映射到毛利/净利、周转、CCC、ROIC/ROE和现金转化。只选能解释差异的指标。多业务按分部比较，无法分拆时明确限制。
优先业务矩阵、毛利率×资产周转散点、费用/现金流关键趋势。市场份额、壁垒和竞争结论需原始证据，竞争优势不能仅由一个财务比率推定。定性差异不给主观综合分。

## B 估值比较
补充同一估值日的股价/股本、市值、现金、债务及其他EV桥接项；历史FY、TTM、预测FY分别列，预测来源/vintage单独标。金融企业选择适合行业的P/B、ROE等，不机械套EV/EBITDA。
逐项说明少数股东、租赁、联营、受限现金、养老金等调整；匹配估值分子与利润分母范围。负或近零分母列NM，不放进有意义倍数的统计。中位数/区间仅在可比样本上计算，不能未经解释得出买卖建议。
用倍数分布图或经营质量×估值散点解释溢价/折价的可能来源；价格时点或预测口径不齐先修正，不可修正则分组或暂不比较。

## 交付与数据不足
共用核心数据/报告约定，保存同行纳入排除理由、源数据和调整桥接。用户只问经营差异时不扩成估值任务；独立竞争研究先在A分支完成，避免另建重复指标体系。
