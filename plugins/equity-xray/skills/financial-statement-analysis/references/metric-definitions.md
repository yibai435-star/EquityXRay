# 确定性指标定义

本文件是公式文档唯一维护点。会计边界见[会计调整](accounting-adjustments.md)，可执行实现见calculate_financial_ratios.py与dupont_analysis.py。


| 指标 | 公式及单位 | 限制 |
|---|---|---|
| 收入YoY | (本期/可比上期−1)×100% | 上期≤0或发生正负切换改金额描述；近零另提示 |
| CAGR | (末值/初值)^(1/n)−1 | 仅正数、同口径，写n年 |
| 毛利/毛利率 | 收入−营业成本；毛利/收入 | 不混营业总收入与营业收入 |
| 费用率 | 该项费用/收入 | 保留财务费用负号，不将降率等同效率改善 |
| 合并净利率 | 合并净利润/收入 | 与归母净利率分开 |
| 归母净利率 | 归母净利润/收入 | 标明归母，不冒称合并 |
| 扣非归母净利率 | 扣非归母净利润/收入 | 不替代主表净利率 |
| 自算总权益ROE | 合并净利润/平均总权益 | 总权益含少数股东；期初/末权益≤0时不作常规ROE |
| 自算归母ROE | 归母净利润/平均归母权益 | 与披露加权ROE分开 |
| 总资产周转率 | 收入/平均总资产 | 对应期间；不默认用期末 |
| 权益乘数（总权益） | 平均总资产/平均总权益 | 不同于1/(1−期末资产负债率) |
| 归母口径权益乘数 | 平均总资产/平均归母权益 | 也受少数股东影响，不解释为纯金融杠杆 |
| 杜邦总权益 | 合并净利率×周转×总权益乘数 | 精确等于自算总权益ROE |
| 杜邦归母 | 归母净利率×周转×归母口径权益乘数 | 精确等于自算归母ROE；不能套披露加权ROE |
| 应收周转/DSO | 收入/平均应收；期间天数×平均应收/收入 | 赊销收入不可得时为近似；票据/合同资产是否纳入保持一致 |
| 存货周转/DIO | 营业成本/平均存货；期间天数×平均存货/营业成本 | 默认净额，若原值另标；周转分子不用收入 |
| 应付天数DPO | 期间天数×平均贸易应付/采购额 | 采购额不可得可用营业成本代理，明确近似；不可用全部流动负债 |
| CCC | DSO+DIO−DPO | 同一窗口/余额口径；不适合时不用 |
| 固定资产周转 | 收入/平均固定资产净额 | 租赁资产、外包/自建使横比差异大 |
| 资产负债率 | 期末总负债/期末总资产 | 不等于有息杠杆 |
| ROA（净利润口径） | 合并净利润/平均总资产 | 对应期间，非EBIT口径；不默认年化 |
| 净现金 | 可动用现金−有息债务 | 净债务的相反数，不把受限现金直接抵债 |
| 净债务 | 定义明确的有息债务−可动用现金 | 定义债务含/不含租赁及现金资产范围 |
| 利息覆盖 | EBIT/利息费用（取费用附注） | EBIT=税前利润+费用化利息的分析近似；资本化利息另列；利息=0不写无限大评级 |
| 简化FCF | OCF−购建长期经营资产支付现金 | 不扣整个投资CF；不等同所有准则下FCFF；租赁还本/并购另列 |
| 现金利润比 | OCF/合并净利润 | 分母≤0时N/M，近零谨慎；累计值=ΣOCF/Σ净利，不是年度比率平均 |
| 现金资本开支率 | 现金Capex/收入 | 非现金转固不等于Capex |
| 有效税率 | 所得税费用/税前利润 | 税前≤0时N/M，递延税/税惠拆解 |
| ROIC | NOPAT/平均投入资本 | 明确操作性EBIT、正常化税率、非经营现金/资产、租赁及商誉；无足够资料不机械算 |

杜邦因子变化使用Shapley：对3因子所有6种替换顺序，计算每因子的边际贡献后平均，贡献和=本期ROE−上期ROE。可处理净利率负值，不用对数法；权益失效则不分解。贡献用百分点，不把数学贡献当经营因果。
