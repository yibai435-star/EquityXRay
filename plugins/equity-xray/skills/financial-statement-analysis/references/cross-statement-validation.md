# 跨三张表验证

先检查输入与口径：资产=负债+总权益；合并净利=归母+少数股东；税前−所得税=净利；CFO+投资CF+融资CF+汇率=现金等价物变动；上年期末与本年期初衔接。重述/并表差异须有来源与调整桥；不要把数据错误解释为经营异常。

| 主题 | 跨表/业务证据链 | 防误判 |
|---|---|---|
| 收入质量 | 收入→应收/票据/合同资产/合同负债→销售商品提供劳务收到现金 | 收现含税、期初回款、预收及票据背书使比例不是恒等式 |
| 库存 | 存货→营业成本→毛利率→CFO | 区分跌价、产销节奏、并表、汇率、非现金变化 |
| 扩产 | 在建→固定资产→折旧→现金CapEx→收入→产能利用率 | 转固≠当期付款；非现金购置、投产爬坡与闲置不同 |
| 融资 | 有息债务→利息/财务费用→融资现金流 | 财务费用含汇兑/利息收入；债务净变动含非现金、租赁及汇率 |
| 并购 | 商誉/投资→收购现金流→并表收入/利润→商誉减值 | 区分支付时点、非现金对价、取得现金、或有对价及分步并购 |
| 利润兑现 | 合并净利→非现金/非经营损益→营运资本变化→CFO | 余额差不自动等于现金影响，优先现金流补充资料 |

重要异常尽量至少两表验证，并引用相关附注。不要把资产负债表变化与CF简单相减配平；保留未解释残差。定量解释不充分时写“方向一致、金额尚未完成勾稽”，不可写因果已证实。
检查结果分PASS/FAIL/NOT_TESTED；技术容差只反映原表精度，不用放宽容差掩盖矛盾。存在重大FAIL先修正；必须交初稿时明示受影响指标和结论限制。
