# 主报告必选指标与研究边界

首要目标是初步理解公司财务，按下表完成六项体检和最后的回报评估。完整/快速版都保留必选指标；快速版可将相关指标合并到5–8张图，不得删除同行或现金质量检查。每个核心指标提供3–5年可比序列，默认5年；最新季度单列。取首年平均余额指标时额外取前一年期末数据，不因报表摘要仅含5年而省略首年ROE。

| 步骤 | 必选数据与图 | 要回答的问题 |
|---|---|---|
| 扣非ROE | 普通归母ROE与扣非ROE历史；扣非杜邦三因子 | 回报水平如何，主营回报是否足够，谁在驱动 |
| 收入及收现 | 营业收入、YoY/CAGR；现金收入比率历史 | 增长来自哪里，收入是否收到现金 |
| 毛利率 | 本公司历史；3–5家同行毛利率 | 产品赚钱能力及横向差异；合并与分部口径分开 |
| 净利润质量 | 销售净利率；净利润现金含量；扣非归母/归母净利润；普通与扣非归母金额 | 最终留下多少、是否现金、是否依赖非经常项目 |
| 资产效率 | 总资产周转历史与3–5家同行；2C优先存货周转，2B优先应收周转 | 利润率/周转模式；最重要的资产占用在哪里 |
| 财务杠杆 | 现金及现金等价物/带息债务历史；现金与债务金额；经营负债单列 | 偿债资源是否覆盖金融债务，高ROE是否由杠杆放大 |
| 现金流验证 | CFO、资本开支、FCF历史，利润到CFO关键调节项 | 上述现金质量是否经得起三表交叉验证 |
| 最终扣非ROE评估 | 分数、质量（靠什么赚钱）、稳定性（近5年，至少3年） | 用一页证据概括回报水平、机制和持续性 |

公式与负分母处理只维护于metric-definitions.md；扣非定义见accounting-adjustments.md；评分规则见roe-assessment.md，禁止另外发明评分表。

## 主报告与专项的分工
- 正常项1–2句；异常项给主要驱动、跨表证据、可能解释和待验证资料。不自动把所有分支查到底。
- 行业分类优先真实经营模式，2C/2B仅决定默认优先分支：2C制造同样可能有渠道应收；2B项目制可能存在大额存货/合同资产。另一个科目重大时一并检查；软件/金融等适配见sector-adaptations.md。
- 内部调用comps-analysis完成同行筛选和口径对齐、earnings-analysis核对最新变化，交接复用底稿，不改变主报告结构。
- 用户另行要求深挖时启动独立deep模式，复用本次证据；DCF/model-update保持独立入口。主报告问题列表是交接对象，不自动变成估值假设。
- 每一必选指标留下“已计算/不适用/披露不足/口径不可比”之一；不把未查数据当正常，不用其他指标静默顶替。
