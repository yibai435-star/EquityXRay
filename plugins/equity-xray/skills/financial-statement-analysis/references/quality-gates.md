# 交付前质量门

## 数据
- [ ] 主体/代码/期间/截止日正确，报告已披露，FY/YTD/Q/TTM不混用。
- [ ] 来源可读，原数附URL/文档和页码/表名，披露/抓取日期及原始单位记录；关键结论追到原表。
- [ ] 单位/币种/合并范围/重述一致；同行可比性有理由，跨分部不重复计算。
- [ ] 上年期末与本年期初衔接；重述/范围变化有来源及调整桥，不将数据断点当经营异常。
- [ ] 资产=负债+权益；利润及归母/少数股东桥接；现金等价物首尾变化勾稽；重大残差已解决/披露。
- [ ] 平均余额有期初；毛利、费用、现金比率、DIO/DSO/DPO、Capex定义正确；正负号正确；缺失非0。
- [ ] 披露/自算/扣非/调整指标区分；杜邦产品和变动贡献复核；负/近零分母和低基数明确。

## 分析
- [ ] 七步完整且篇幅按异常倾斜，正常项简述；深挖/对比不强套全报告。
- [ ] 每个重要异常有相对基准、财务影响、主要子项、跨表证据、业务解释、替代解释、验证方法。
- [ ] 完整异常扫描覆盖清单留状态，未核查不称正常；不靠固定阈值定性或推断造假。
- [ ] 事实/公司管理层/外部证据/推断有区别；毛利提高不直接等于竞争力增强，数学归因不等于因果。
- [ ] 最后回到经营机制和战略选择；待验证问题具体，可指导下一阶段查证。

## 图表与文件
- [ ] 核心七节有图或数据不足原因；快速5–8图；所有图紧跟图表结论、怎么看/发现/解读/继续拆解。
- [ ] 数图一致、柱从0起、负值/断点诚实；率变化单位正确，图题不过度推断，来源有链接。
- [ ] HTML自包含、无CDN；图/表不溢出；中文清楚；实际渲染摘要为1页且正文/最长图/附录可读。
- [ ] Excel/CSV与JSON可复核，原始/派生/公式/来源/调整/同行/检查/claim链齐全。
- [ ] 默认未生成PPT；文件保存成功后才链接；未完成视觉或数据验证时如实注明具体限制。
