## 分析
- [ ] main-report-contract.md全部必选指标有3–5年数值或具体缺口；首年平均余额额外取上一年期末。
- [ ] ROE确为扣非或明确缺口；Non-GAAP未冒充扣非；利润占比分子分母均归母。
- [ ] 毛利率、总资产周转率各有3–5家同期间可比同行；缺口/例外有说明；2C/2B优先分支与实际经营模式匹配。
- [ ] 收入收现不用CFO代替；现金债务覆盖不用广义cash position代替；亏损/近零利润不机械解释现金含量及扣非占比。
- [ ] 综合评估有分数/质量/稳定性，评分政策与样本透明；数据不足显示暂不评分；未将分数冒充信用/投资评级。
- [ ] 七步完整且篇幅按异常倾斜，正常项简述；深挖/对比不强套全报告。
- [ ] 重要异常有相对基准、主要驱动、跨表证据及待验证问题；主报告仅展开影响初步判断的部分，深挖另行触发。
- [ ] 完整异常扫描覆盖清单留状态，未核查不称正常；不靠固定阈值定性或推断造假。
- [ ] 事实/公司管理层/外部证据/推断有区别；毛利提高不直接等于竞争力增强，数学归因不等于因果。
- [ ] 最后回到经营机制和战略选择；待验证问题具体，可指导下一阶段查证。
