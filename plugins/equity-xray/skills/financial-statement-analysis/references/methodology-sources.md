# 官方方法入口

以下是方法入口，不是公司数据来源。实际执行时核实适用司法辖区、版本、生效时间及企业选用政策；不能永久假设规则不变。

- 中国证监会《公开发行证券的公司信息披露编报规则第9号——净资产收益率和每股收益的计算及披露》（2010年修订）：https://www.csrc.gov.cn/csrc/c101864/c1024649/content.shtml
  用于核实披露ROE/扣非ROE口径；自算期初期末平均指标另标。
- 中国证监会《公开发行证券的公司信息披露解释性公告第1号——非经常性损益（2023年修订）》：https://www.csrc.gov.cn/csrc/c101954/c7451398/content.shtml
  用于核实公司非经常性判断及税后归母调整，不仅按报表行名分类。
- IFRS Foundation IAS 7：https://www.ifrs.org/issued-standards/list-of-standards/ias-7-statement-of-cash-flows/
  核实现金等价物、现金流分类、非现金交易及报表调节；IFRS 18相关修订的适用时点和提前采用需逐公司核实。

上述官方入口在2026-09-27创建技能时查阅。研究报告引用实际公司报告页码和来源，不引用技能本身作为数据证据。
