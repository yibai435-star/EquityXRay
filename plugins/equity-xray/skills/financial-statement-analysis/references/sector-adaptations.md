# 行业适配与失效场景

保留回报→增长→盈利→资产质量/效率→资本/杠杆→现金/质量主线，替换无经济含义的指标，不强行生成毛利率、库存或CCC。每个替换写理由，并用当期监管/公司官方定义核实行业指标。

主报告先判断实际客户/回款/资产模式。2C消费、零售、整车等优先存货周转率和库存结构；2B制造、软件、项目交付等优先应收周转率和回款周期。混合业务按重大分部兼看两项；2C渠道应收、2B在制库存或合同资产重大时不得略过。轻资产服务无存货则标不适用；不因客户是消费者就忽略分期应收。

| 类型 | 应改用/重点补充 | 不可机械套用 |
|---|---|---|
| 银行 | 净息差、利息/手续费收入、成本收入比、不良/关注贷款、拨备、资本充足、资金结构 | 存货CCC；普通企业净债务；经营CF弱即利润差 |
| 保险 | 保险服务业绩、投资收益、承保利润/综合成本率（财险）、新业务价值（适用寿险）、偿付能力 | 把保费直接当会计收入；跨准则机械同比；普通毛利率 |
| 证券 | 经纪/投行/资管/交易收入、资本回报、净资本和风险敞口 | 投资收益一律当非主营；普通库存周转 |
| REIT/房地产 | 出租率、租金/同店NOI、合同销售/结转、预收、完工/交付、债务期限、分派现金 | 预售合同负债全当融资；开发周期忽略；公允价值盈利视为现金 |
| 软件/平台 | 订阅/续约、递延收入、总额净额、研发资本化、股份支付、单位经济 | 无库存硬算DIO；只看销售费用率判断获客效率 |
| 半导体/制造 | 量价、产品代际、库存结构/跌价、良率/利用率、研发、外包自建、周期 | 不同芯片品类直接ASP比较；以研发率高低判断创新强弱 |
| 零售/消费 | 同店、开店/关店、渠道、店效、租赁、促销、加盟/直营 | 将开店增收认作同店增长；忽略租赁和收入确认 |
| 控股/多业务 | 分部可比池、资本配置、内部交易、少数股东 | 一个行业平均覆盖全公司 |
| 负权益/持续亏损 | 绝对利润、现金消耗、融资/偿债、权益变动与业务拐点 | 正ROE幻象、利润CAGR、现金比率质量评级 |

数据不足时保留研究问题，不靠行业刻板印象补数。调整后需在摘要和附录标明指标替换，标准脚本不能计算的扩展指标另建计算轨迹与来源。
