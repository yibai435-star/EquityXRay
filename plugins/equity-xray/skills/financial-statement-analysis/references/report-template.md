# 上市公司财务研究报告模板

## Executive Summary（1页，可独立阅读）
3–5个核心发现回答：增长来自哪里、ROE由什么驱动、盈利如何变化、利润/现金质量、最重要异常、下一步研究方向。
附核心指标表6–8行：最新值、历史变化、核心解释。有证据时列2–4个重要异常，无充分证据不凑数。列3–5个研究问题。

## 正文顺序
1. ROE与杜邦
2. 收入增长与业务结构
3. 毛利率与产品盈利能力
4. 费用与净利润
5. 资产周转
6. 财务杠杆
7. 现金流与利润质量
8. 财务异常扫描
9. 财务→业务/战略解释
10. 待验证问题（3–8个，给所需证据/验证方法）

## 每节结构
【核心结论】1–3句→【图表】→【数据事实】→【分析】→【是否异常】→有异常才【进一步拆解】。
正常项图+1–2句说明；异常允许递归加图加证据，禁止平均篇幅。核心七步至少1图，无法作图说明数据缺口；异常扫描与战略部分用证据矩阵或机制图。图表选择与图下固定项仅维护于[chart-guide.md](chart-guide.md)。

## Appendix 数据底稿
核心3–5年数据、同行比较、公式/计算轨迹、来源与页码、会计口径、一次性调整、同行选择理由、完整异常覆盖状态。结论→metric_id→source_id可追溯；缺失不能解释为正常。

## 模式变体
- 快速：一页结论＋5–8张关键图＋核心异常＋相应底稿。
- 深挖：目标节点及递归分支、跨表验证、替代解释、待验证问题，不重跑无关七步。
- 专项比较、季度、DCF、模型更新：使用各自模块模板，不硬套本报告。
- 汇报PPT：仅明确要求时基于已验证报告压缩8–12页。
