# 指标树：异常后拆什么

只在异常识别触发后选择有解释力的分支；缺少分部披露时停止并留下问题，不强行填齐。公式仅维护于[指标定义](metric-definitions.md)，异常判据只维护于[异常识别](anomaly-detection.md)。

| 根节点 | 一级驱动 | 二级拆解与待取证据 |
|---|---|---|
| ROE | 净利率、总资产周转、权益乘数 | 对主要因子做杜邦贡献；检查权益扩张/缩水、增发、分红回购、减值、少数股东变化；区分披露加权和自算值 |
| 净利率 | 毛利率、销售/管理/研发/财务费用率、信用减值、资产减值、投资收益、公允价值、其他收益、营业外损益、税率 | 费用金额和收入分母；费用资本化/股权激励；一次性及税效；归母与少数股东；解释利润桥残差 |
| 收入 | 销量、ASP、产品结构、地区、客户、渠道、新老业务、并购 | 按披露挑选维度；量价仅同产品同单位，组合ASP需辨别结构；并购/汇率/有机增长有来源才拆；核查总额净额法 |
| 毛利率 | 售价、原材料、产品结构、利用率、供应链、汇率、渠道、竞争、促销降价 | 分部权重与毛利；采购价、良率、折旧、外包、自建、新品爬坡、低毛利业务退出 |
| 总资产周转 | 应收、存货、固定资产、在建工程、其他重大资产 | 金融资产、并购/剥离、产能投放；资产增加是否形成订单、收入与现金 |
| 应收 | 应收增长vs收入、DSO、客户结构、坏账准备、信用减值、回款周期、CFO | 原值/净值、账龄、逾期、期后回款；适用票据、合同资产、保理；信用放宽与收款困难两种解释 |
| 存货 | 存货增长vs收入/成本、原材料、在产品、库存商品、DIO、跌价、毛利、CFO、行业库存周期 | 库龄、产销率、订单覆盖、渠道库存、期后出货；区分主动备货、扩产、需求增长、渠道积压、产品滞销 |
| 净利与CFO背离 | 非现金及非经营损益；应收、存货、预付、应付、合同负债、其他经营资产负债 | 用净利润到CFO调节表核实；余额差不直接当现金影响；再单独检查CapEx对FCF的影响 |
| 杠杆/偿债 | 经营负债、有息债务、租赁、期限、可用现金、利息覆盖 | 供应链金融、受限现金、融资安排、利息资本化、授信；财务费用不等于利息支出 |
| 商誉/在建/预付款 | 资产和净资产两端、项目、交易对手 | 并购资产组、减值假设、工程进度/延期、转固/折旧、产能利用率、回款与关联关系 |

**现金分支边界：现金CapEx一般属于投资活动，不能直接作为净利润与CFO差额的原因；先完成CFO调节，再走CFO→CapEx→简化FCF分支。**

利润形成桥应覆盖毛利、税金及附加、四项费用、有符号各项收益/减值、营业外收支、所得税、少数股东损益；与“上期到本期的利润变化桥”分开。未解释项保留残差并回源，不塞入没有证据的“其他”。

每次递归记录：节点、相对触发依据、变化贡献、已有证据、替代解释、下一层、停止理由。先拆影响最大的2–3项；主因已证实、余项影响有限且可说明、进一步拆不能改变判断或披露不足时停止，不按固定层数机械截断。

## 主报告边界与扣非入口
主报告以扣非ROE/扣非归母利润率作为核心入口，普通杜邦仅辅助解释；净利率、周转、杠杆公式及权益范围以metric-definitions.md为准。异常在主报告先识别主要一级贡献项并给跨表验证；后续全面递归深挖仅在明确deep或必要专项调用中执行。不将Non-GAAP作为扣非树根。
