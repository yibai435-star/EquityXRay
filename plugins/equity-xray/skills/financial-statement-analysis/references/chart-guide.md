# 财务问题→图表选择

| 要回答的问题 | 优先图形 |
|---|---|
| 扣非ROE过去如何变化 | 普通/扣非归母ROE历史双折线；调整缺口单独标明 |
| 公司与同行ROE差距 | 分组柱形或点图 |
| 收入增长及速度 | 收入柱形+YoY对齐小图；必要时明确双轴 |
| 收入是否收现金 | 现金收入比率3–5年折线，销售收现金额与收入柱形 |
| 毛利率同行位置 | 本公司历史折线+3–5家同行同年点图/分组柱 |
| 净利润质量 | 销售净利率、净利润现金含量、扣非/归母利润三项历史小图；亏损分母配金额图 |
| 产品/地区贡献 | 同一维度的收入堆积柱，不混维度 |
| 毛利/费用趋势 | 折线或分组柱；异常时分部结构或贡献桥 |
| 利润如何形成、为什么变化 | 分别使用毛利至净利瀑布、上期至本期变化瀑布 |
| 杜邦驱动 | 因子趋势+带数值拆解图或贡献图 |
| 资产效率与经营模式 | 周转趋势；同行毛利率或净利率×周转散点（标题写清所用口径） |
| 净利是否变成现金 | 净利和CFO双序列；必要时现金调节桥 |
| 偿债资源 | 现金/有息债务分组柱、负债性质/期限结构 |
| 现金等价物债务覆盖 | 现金及等价物/带息债务3–5年趋势；金额并列，不用cash position替代 |
| 最终回报评估 | 同口径扣非ROE5年折线/年度位置分；质量与稳定性证据表 |
| 再投资如何影响现金 | CFO、现金CapEx、FCF；不可把整个投资CF当CapEx |
| 异常覆盖与业务解释 | 证据状态矩阵、指标树或机制图；不做主观风险评分 |

每图紧跟“图表结论”1–3句，回答“所以呢”；配【怎么看】一句、【发现】1–3项、【解读】、【是否继续拆解】及下一层/停止理由。每图的发现/解读可兼作本节数据事实/分析，不重复写。
标题优先直接表达证实的数据事实；证据不足用中性标题，不能靠图题先下竞争力/造假结论。
柱从零起；负值有零线；折线断点不补数；区分百分比与百分点。单位、期间、币种、图例与来源完整。收益/减值保留实际符号，瀑布有勾稽；缺数据则改图或说明缺口。
正常项简图简评；异常才加下一层图。绘图执行交给通用工具，本文件不维护绘图库教程。技术输出遵从[共享报告约定](../../../shared/report-conventions/conventions.md)。

只有局部数据时仍考虑可诚实表达的图：例如已知收入与存货两项同比，可画同比对比并注明“用户提供、未经原表核验”；金额缺失不妨碍该图，但不能补画DIO或现金贡献。真正无法成图的分支才列缺口。
