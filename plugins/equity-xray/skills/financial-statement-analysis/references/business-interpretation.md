# 从财务现象到经营与战略

建立“财务现象→量化驱动→业务原因→战略含义→替代解释→验证证据”，不能停在数字，也不能跳过证据直接给策略。

| 信息性质 | 写法与边界 |
|---|---|
| 【财务事实】 | 可由报表/附注/计算复核，列期间、口径和来源 |
| 【公司管理层解释】 | 引用管理层披露，明确这是公司说法，不能自动当成已验证原因 |
| 【外部证据】 | 行业价格、客户/渠道、竞品、份额、供应链等有可核实来源的信息；仍检查时效、范围与统计口径 |
| 【分析推断】 | 连接证据形成假说，给不确定性、替代解释、支持/反驳证据；不能写成事实 |

毛利率下降须核实价格、原料、产品组合、汇率、竞争、渠道和新品周期；低毛利业务退出可能抬升整体毛利率。毛利变动本身不直接证明竞争力变化。
存货增长可来自订单备货、扩产，也可来自渠道压货或滞销；分部结构、库龄、出库与订单才可区分。利润现金背离也可能是时点、税款或非现金损益。

对重要变化讨论可选择的路径：产品定位、市场/客户组合、渠道、自建/外包、投入节奏、业务组合、资本配置。对每条路径说明约束、所需资源、兑现时间、反证和验证指标；财务症状不直接转换成“加强管理”等口号。
证据不足时提出可执行研究问题，例如“新增库存有多少由已签订单覆盖，期后出货是否兑现？”不要只写“关注存货”。
