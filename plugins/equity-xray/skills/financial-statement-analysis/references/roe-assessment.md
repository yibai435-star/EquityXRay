# 扣非ROE综合评估：分数、质量、稳定性

三部分并列，全部追溯到主报告数据。分数用于描述扣非回报的同行相对水平，质量和稳定性分别解释，不将主观印象和不可比财务项硬加总。

## 1. 分数（0–100，项目自定义同行位置分）
这不是监管/信用评级、投资建议或“公司总分”。固定同一3–5家同行，采用近3–5个连续完整财年，在共同可比年度使用同一调整政策和同一种ROE计算口径。

每年分数=100×（扣非ROE严格低于目标公司的同行数量+0.5×并列同行数量）/有效同行数量；最终分数为各年分数的中位数。至少3家同行、至少3个连续共同财年；不得更换每年的同行池、重加权缺失值或用普通ROE/Non-GAAP代替。并列以原数为准，数值容差仅消除浮点误差。报告附年度分数、同行池、期间、公式、样本量。

高相对分可能仅表示亏损更小，必须同时列扣非ROE绝对值、近年正回报次数。分数粗粒度，显示整数，不贴红黄绿或优秀/及格标签。数据不足则显示“暂不评分：具体缺口”，不编数字。`scripts/assess_adjusted_roe.py`只做确定性相对位置与稳定性统计。

优先披露加权扣非ROE，但横向不足时统一改用自算平均归母权益口径；不能混用。法定扣非和完整税后归母桥接的分析调整分别标明；分析调整只在同行共同政策可复核时评分，标题写“分析调整ROE评估”，不冒充法定扣非。

## 2. 质量：靠什么赚钱
用扣非杜邦指出高利润率、高周转、高杠杆或组合驱动；再结合主营/分部毛利来源、现金收入比率、净利润现金含量、扣非/普通归母利润、现金等价物/带息债务解释。
区分“盈利来源”与“现金来源”：供应商账期可支持CFO，不能当利润创造；一次性收益可抬升普通ROE，不能当扣非ROE驱动。数学贡献不是经营因果。不按比率孤立判好坏。

## 3. 稳定性：近5年变化
显示扣非ROE逐年值、最新与首年变化（百分点）、中位数、最大/最小、总体标准差（百分点）、正回报年数/有效年数；必要时指出转型/周期拐点。默认5年，只有3–4年明确覆盖期；不足3年不作稳定性结论。标准差不能区分持续改善与随机波动，配趋势解释；跨正负或均值近零不用变异系数。

## 缺口时的交付
三维均保留：分数暂缺；质量给已有经营证据并标适用ROE；稳定性可使用所选历史中最新连续、同口径的至少3个有效扣非财年，并明确有效段起止及未覆盖年份；政策断点/缺失不能连接为连续趋势；不足时可列已披露年度数值而不判稳定。不得靠总毛利或普通ROE生成扣非总评。附下一步所需扣非调整表、税效、少数股东、同行数据。

## 独立依赖与窗口说明
分数依赖固定同行与共同评估年；稳定性只依赖目标公司的有效连续同口径历史，经营质量依赖已核实的业务与现金证据。无关公司/期间的失败检查不影响这两个数值维度，同行失败可阻止分数但不抹掉目标公司有效稳定性。请求年份缺失必须保留requested_years/missing_years，历史统计显示实际起止、partial状态及缺失年份，不宣称完整覆盖或覆盖未披露的最新年。
