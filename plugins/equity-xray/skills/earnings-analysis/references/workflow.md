# 季度业绩工作流

## 输入与范围
公司、季度、截至时间；优先季报/公告/IR和电话会原文。发布日期前一致预期必须有来源与时点；无数据记缺失。区分单季度与累计，Q4差额需要同口径全年与九个月数据。单季度资产收益率不随意年化。

## 执行
1. 列实际、同比可比期、环比（考虑季节性）、发布前一致预期、上一版及新版指引。对收入/利润/每股收益核对GAAP与调整口径。差额与百分比要区分；负基数比较改报绝对变化。
2. 收入按产品、量价、地区或客户拆到披露允许层级。利润按毛利、费用、减值、非主营、税率拆主要项；出现异常调用核心指标树。
3. 检查应收/存货/CFO和当季季节性；公司调整后利润与法定利润桥接。管理层解释与外部证据分栏。
4. 分析指引的口径、区间与变化；区分经营变化、发布时间不同、汇率/并购与预期误差。
5. 输出最重要结论、关键比较表、收入/利润或指引差异图、异常证据与待验证问题。仅在可比数字齐全时画精确桥接。

## 边界与失败处理
没有原始发布资料先检索；未披露则说明最新可得期，不虚构“刚发布”。无一致预期可完成同比/环比和指引解读。预测影响标分析推断；用户要求更新模型时交接model-update，携带实际数据版本及建议变更，不直接覆盖工作簿。
