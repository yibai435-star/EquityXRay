# DCF专项工作流骨架

## 输入
公司、估值日、币种、已披露历史、业务驱动、股本/稀释项、债务与可用现金、折现率输入。可复用财报模块已验证数据；历史趋势不是未来假设。无法获得关键数据时先列缺口并完成可得历史整理，不编造精确目标价。

## 模型
1. 明确FCFF/FCFE及行业适用性。银行/保险等资本监管行业不机械套工业企业FCFF，先选择匹配框架并说明。
2. 基于量价、分部、毛利、费用、税、资本开支、折旧和经营营运资本建立显性预测与情景。假设有依据、日期和敏感性，不硬编码通用税率/CapEx区间。
3. FCFF = EBIT×(1−适用经营税率)+D&A−CapEx−经营营运资本增加；损失、递延税与税收优惠需建模，不能机械给负税益。折现币种、名义/实际及期间一致。
4. WACC按权益与融资债务的市场价值权重，债务税盾需可用；不可用净债务/企业价值代替融资债务权重。净现金不产生负债务权重。FCFE用股权成本折现。
5. 永续终值要求WACC>g且稳定期利润率、再投资和增长互相一致；退出倍数作交叉检查并标来源。年末/年中折现与估值stub期明确。
6. FCFF企业价值到股权价值桥接单列融资债务、可用非经营现金、少数股东及其他必要调整；避免现金/金融资产双重计入。用适当稀释股数得每股值。
7. 输出WACC×g敏感性、情景区间、终值占比和价值桥接；区分可验证事实与估值假设。价格比较必须说明时点，估值不等于事实。

## 校验与边界
使用Spreadsheets等通用工具保留输入/公式分离，禁止把结果全写成硬编码。重算后检查公式错误、平衡、现金流符号、终值条件、桥接、股数单位、情景联动与敏感性合理性。引擎不可重算则明确未验收项，不谎称已重算。此阶段不提供专业机构估值模板库或自动实时市场数据连接。

## 方法核对来源
WACC融资权重与口径参照NYU Stern Aswath Damodaran definitions： https://pages.stern.nyu.edu/~adamodar/New_Home_Page/definitions.html 。输入数据仍须按研究时点重新核实。
