# 共享报告与执行约定 v1

研究Skill负责选择问题、证据、比较、异常与解释；references维护方法；领域脚本只做确定性计算/校验；通用能力负责检索、图形执行、表格、文档和持久保存。

| 工作 | 优先通用能力 | 回退 |
|---|---|---|
| 原始资料 | Web研究、用户文件、已授权数据连接器 | 无法获得时列缺口，不假装连接 |
| 数据分析/可视化 | 可用Data Analytics工作流、Python/Notebook | 领域指标脚本供复算，不再造统计/绘图库 |
| Excel | Spreadsheets技能，保留公式/输入/来源与重算结果 | CSV＋JSON可复核底稿；未能重算必须说明 |
| HTML/文档 | 可用报告生成、渲染及文件能力 | 现有render_report.py仅兼容回退 |
| 持久保存 | 当前Library技能；既有文件保留身份/版本 | 能力缺失如实说明，不声称保存成功 |

默认中文，自包含文档型HTML、内嵌SVG/PNG及CSS、无远程运行依赖，配Excel/CSV和JSON。标题有主体、期间、截止日、单位。每图可核数、源可追、负值/缺失诚实、图下解读不空泛；详细选图由财报Skill的chart-guide.md维护。
报告是一页摘要+核心正文+数据附录。季度、比较、估值、模型更新使用各自正文结构。专项模型需要随假设更新时使用真实Excel公式；现有历史底稿的文本公式/依赖图可复算但不冒称交互Excel模型。
仅明确要求时生成PPT或在线发布。用户本次范围/格式指示优先；不因外部模板强制多轮确认。疑义不影响结果时合理假设并注明，实质影响主体或关键输入时才问。
交付前检查数值勾稽、来源、图数一致、缺口、口径与推断强度；实际渲染摘要/最长图/附录并核对摘要1页。无法渲染时说明具体未验证项，不能冒称验证通过。
